# Petal Sort

Сортує фото й відео з папки за змістом. ШІ працює прямо в браузері, файли нікуди не завантажуються.

## Як запустити

1. Встанови [Node.js](https://nodejs.org), якщо його ще нема.
2. Двічі клікни `start.bat` (або виконай `node server.js`).
3. Відкрий `http://127.0.0.1:5174` у Chrome або Edge.

## Як користуватись

1. **Обрати папку**: фото й відео збираються купою в центрі.
2. **Сортувати**: ШІ розкладає файли по категоріях. Кожну категорію можна відкрити й виправити.
3. **Розкласти по папках**: файли переміщуються (або копіюються, якщо ввімкнена галочка «Залишити оригінали на місці»).

Дублікати знаходяться за вмістом файлу й потрапляють у папку «Дублікати».

## Як це працює

Для розпізнавання використовується модель [CLIP](https://github.com/openai/CLIP) через [Transformers.js](https://github.com/huggingface/transformers.js). Вона завантажується один раз (~150 МБ), далі кешується в браузері й працює офлайн на твоєму комп'ютері. Ніяких API-ключів і оплати.

Категорії та їхні описи для моделі лежать на початку скрипта в `index.html`, у блоці `CATS`.

## Обмеження

- Потрібен Chrome або Edge (доступ до папок через File System Access API).
- Формати на кшталт HEIC браузер часто не відкриває, такі файли потрапляють в «Інше».
